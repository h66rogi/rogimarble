# 게임 규칙과 보드

## 후원 판정

후원 규칙은 채널 설정에 등록한 별풍선 개수와 **정확히 일치**할 때 실행됩니다. 후원을 합산하거나 등록 개수의 배수로 해석하지 않습니다. 한 후원은 한 규칙에 대응하며, 같은 개수를 중복 등록할 수 없습니다. 연속 주사위는 채널에서 허용하고 해당 개수의 `rollCount` 규칙을 따로 등록해야 합니다.

`presets/streamer-initial.json`은 가져오기용 예시입니다. 서버는 이 파일을 매 요청에 자동 적용하지 않습니다. 운영자는 규칙의 개수, 이름, 활성화 여부, 동작, 문구, 실드 정책과 목적지 입력 방식을 채널 설정에서 관리합니다.

## 보드

`presets/streamer-board.json`은 9열 × 6행 외곽의 26칸 보드 예시입니다. 칸의 stable ID, 경로 순서, 표시 내용과 효과는 분리되어 있습니다. 화면 크기만 바꿔도 칸 수와 게임 경로는 유지됩니다. 칸 수를 바꾸는 편집은 기존 칸의 ID와 참조를 검토한 뒤 적용합니다.

효과는 칸 이름이나 배열 위치가 아닌 타입과 매개변수로 결정합니다. 보드 정의는 미션, 선택 미션, 경로 이동, 목적지 선택, 방향 변경, 이동 제한, 다음 주사위 변경, 적립·정산, 아이템 지급 등을 표현합니다. 통과 효과는 이동 경로를 다시 바꾸지 않는 타입으로 제한됩니다. 미정 효과가 있는 보드는 게시와 세션 시작에서 거부됩니다.

## 차례와 특수 효과

- 서버가 주사위 값과 경로를 계산하고 한 번 확정한 결과를 재사용합니다.
- 적립 칸은 지정 수량을 더하고, 정산 칸은 누적 수량을 차감한 뒤 단일 미션으로 기록합니다.
- 다음 주사위 배수는 지정된 다음 이동 한 번에 적용합니다.
- 무인도는 휴식 차례와 탈출 판정을 별도로 처리합니다. 탈출용 더블 판정은 일반 이동 주사위와 구분됩니다.
- 세계여행은 예약된 다음 정상 차례를 목적지 직접 이동으로 처리합니다. 목적지는 설정된 권한과 후보 칸에 따라 확정합니다.
- 운영자가 방향을 바꾸면 아직 확정되지 않은 다음 이동부터 반영됩니다. 위치 보정은 자동 이동을 일시정지하고 도착 칸 효과 정책을 적용합니다.

정확한 스키마와 검증은 `packages/game-core/src/board-definition.ts`, 실행 결과는 `apps/api/src/board-support.ts`와 `apps/api/src/travel-turn.ts`를 기준으로 합니다.

## 효과 타입

| 효과 타입 | 의미 |
| --- | --- |
| `mission`, `choice_mission` | 문구 또는 선택 입력을 포함한 미션을 기록 |
| `move_steps`, `choose_destination` | 경로를 따라 추가 이동하거나 선택한 칸으로 이동 |
| `set_direction`, `movement_lock` | 다음 이동 방향 또는 차례 제한 조정 |
| `modify_roll` | 정해진 횟수의 후속 주사위 이동을 변경 |
| `counter_add`, `counter_settle` | 세션 카운터에 적립하거나 정산 |
| `grant_item` | 공유 인벤토리에 아이템 지급 |
| `none` | 게임 상태를 바꾸는 효과 없음 |

`onLand`는 도착한 칸에서, `onPass`는 경로를 지나는 칸에서 평가합니다. 추가 이동이 다시 효과를 발생시키면 같은 원인 아래 별도 결과로 기록합니다. 실행기는 연쇄 효과의 반복과 중복 적용을 제한합니다.
