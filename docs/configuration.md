# 설정과 게시

채널 설정은 후원 규칙, 아이템, 보드와 방송 배치를 구분해 관리합니다. 후원 규칙과 아이템은 **초안 저장 → 서버 검사 → 게시** 순서로 적용합니다. 게임판은 채널당 하나를 보여주며 **게임판 저장** 한 번으로 서버 검사와 다음 게임 적용을 처리합니다. 저장 요청에는 `expectedRevision`을 보내며, 충돌 시 다른 편집을 덮어쓰지 않습니다.

## 후원 규칙과 아이템

후원 규칙의 별풍선 개수는 채널 안에서 고유해야 합니다. 동작은 규칙 ID와 타입으로 판정하며 표시 이름에 의존하지 않습니다. 미션의 실드 허용 여부와 소모 수량은 미션별 설정입니다. 아이템 정의의 지급 기본값과 진행 중 세션의 실제 재고는 별개입니다.

## 보드 편집

칸의 이름, 꾸미기, 도착·통과 효과와 경로 순서를 편집할 수 있습니다. stable ID는 칸 내용과 함께 유지합니다. 보드 크기, 외곽 행·열, 중앙 위젯과 주사위 설정은 각각 별도의 값입니다. 경로 미리보기는 설정을 검사하기 위한 계산이며 실제 게임 명령을 생성하지 않습니다.

저장한 게임판은 다음 게임부터 사용합니다. 저장한 판이 없으면 기본 26칸 판으로 바로 시작하며, 첫 게임을 시작할 때 서버가 해당 판을 기록합니다. 기존 저장본에 실행할 수 없는 동작이 있다면 직전 정상 판을 사용하고 화면에 이유를 표시합니다. 새로운 저장에서는 실행 불가능한 칸 동작을 거부합니다. 진행 중 세션은 시작 당시의 판을 유지합니다. 진행 중 판을 바꿔야 할 때는 의미가 호환되는 버전만 별도 서버 명령으로 적용하며, 진행을 일시정지한 상태에서 기존 위치와 기록을 보존합니다.

## 방송 스타일

보드 테마, 글꼴, 패널 문구와 기본 배치는 화면 미리보기에서 확인합니다. 테마는 보드의 표시만 바꾸며 칸 ID, 경로, 효과와 게임 상태를 바꾸지 않습니다. 통합 오버레이의 실제 위젯 위치·크기·표시 여부는 실시간 배치에서 관리합니다. 적용 방법은 [OBS 오버레이](overlays.md)를 참고하세요.

## 적용 시점

| 설정 | 편집 내용 | 적용 시점 |
| --- | --- | --- |
| 후원 규칙 | 개수, 동작, 미션·아이템·목적지 매개변수 | 게시 이후 수락한 요청 |
| 아이템 | 정의, 이름, 지급 단위와 사용 규칙 | 게시 이후 새 동작 |
| 보드 | 칸, 경로, 효과, 주사위와 중앙 위젯 | 저장 후 새 세션 시작 시 |
| 방송 스타일 | 보드 테마, 글꼴, 패널 문구와 기본값 | 게시된 스타일을 읽는 방송 화면 |
| 실시간 배치 | OBS 위젯의 위치·크기·표시 여부 | live 저장 후 방송 화면 |

저장 실패나 revision 충돌은 편집 중인 값을 유지한 채 표시합니다. 조회 실패를 빈 설정으로 대체해 게시하지 않습니다. 사용자가 미리보기에서 움직이는 말이나 효과를 확인해도 그 동작은 실제 후원이나 세션 명령을 만들지 않습니다.
