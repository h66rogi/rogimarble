# 운영 콘솔

운영자는 접근 토큰으로 로그인한 뒤 채널의 게임 상태, 보드, 최근 후원과 대기 작업을 함께 확인합니다. 홈에서 게임 세션을 시작·일시정지·재개·종료하고, 한 건 진행, 수동 주사위, 방향 변경, 말 위치 보정과 재고 조정을 실행합니다.

## 방송 중 조작

- **수동 주사위:** 실제 서버 주사위 결과를 생성합니다. 후원 내역으로 기록하지 않고 운영 명령으로 남깁니다.
- **방향:** 다음 미확정 이동에 적용합니다. 이미 확정된 경로와 재생 중 연출을 바꾸지 않습니다.
- **위치:** 보드의 칸을 선택해 말을 옮깁니다. 자동 이동을 일시정지하고 이전 위치 연출을 무효화합니다.
- **재고와 상태:** 아이템 수량, 적립 수량, 이동 제한과 배수를 조정합니다. 전후 값과 작업자를 원장에 기록합니다.
- **대기 작업:** 목적지 선택, 보류, 취소와 실패한 작업의 재시도를 요청별로 처리합니다. 완료된 후원은 다시 실행하지 않습니다.

후원 내역에는 수집 시각, 후원자, 개수, 메시지, 일치한 규칙과 처리 결과를 표시합니다. 미등록 개수도 내역에 남습니다. 운영 명령은 후원 합계에 포함하지 않습니다.

## 설정과 방송 화면

상단의 **게임 규칙**에서 후원 규칙과 아이템을, **보드 설정**에서 게임판과 방송 스타일을 편집합니다. 운영 중 OBS 화면의 배치는 오버레이 탭에서 조정합니다. 설정 게시와 현재 세션의 수동 보정은 서로 다른 작업입니다. 자세한 적용 시점은 [설정과 게시](configuration.md)에 있습니다.

**개발자도구**에서는 collector 연결, 후원 처리, 방송 조회, 입장·채팅 수집 테스트와 운영 기록을 확인합니다. 다른 채널 조회나 채팅 테스트는 게임의 운영 수집 대상을 바꾸지 않습니다. [수집기 연결](collector.md)을 참고하세요.

## 세션과 기록

새 세션에는 선택한 게시 보드를 적용합니다. 일시정지는 자동 이동 진행을 멈추고, 한 건 진행은 대기 작업을 지정된 순서로 처리합니다. 종료한 세션의 기록은 조회할 수 있으며, 이후 수신한 후원을 종료된 세션의 결과로 소급 처리하지 않습니다.

세션 기록은 원인 후원 또는 운영 명령, 적용한 설정, 서버 결과를 연결합니다. 아이템 조정은 재고 원장에 전후 수량을 남깁니다. 실패한 요청을 확인할 때는 같은 명령 ID의 저장 결과를 먼저 조회하고, 중복 후원 처리나 중복 아이템 지급이 발생하지 않도록 기존 작업의 상태를 확인합니다.

목적지 입력이 필요한 후원은 대기 요청으로 표시합니다. 운영자 선택과 해당 후원자의 채팅 선택 중 설정된 방식을 사용하며, 한 요청의 목적지는 한 번만 확정합니다. 다른 후원자의 채팅이나 만료된 요청으로 말을 이동시키지 않습니다.
