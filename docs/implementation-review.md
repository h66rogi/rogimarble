# 초기 구현 리뷰

2026-09-21. 주 대화 Operator와 GPT-5.6 Sol 구현자/교차 리뷰가 발견한 실행 결함을 기록한다.
계획 리뷰와 구분하며 실제 검증 결과는 [구현 진행 기록](implementation-status.md)에 남긴다.

| 대상 | 발견한 문제 | 조치와 확인 |
| --- | --- | --- |
| 인증 | 쿠키 이름 길이 계산으로 정상 쿠키를 잘못 잘랐음 | 상수 길이 사용, PG/HTTP 및 브라우저 로그인 확인 |
| 서버 명령 | 전역 명령 ID 조회에 채널·세션·작업자 범위가 빠지고 동시 재전송이 경합 | 범위 hash/검사와 advisory lock, 동일 create/roll 동시 요청 회귀 검사 |
| 입력 | 미지원 명령 type이 위치 보정 분기로 들어갈 수 있었음 | strict 런타임 분기/입력 검증, 잘못된 입력 4xx 검사 |
| 초기 웹 | 검증용 판의 시작 버튼이 막혔음 | 명시적 검증 세션 시작 허용, 원본 특수 효과 보드 거부 유지 |
| 연출 | Lottie JSON이 빈 path를 만들고 정지한 말이 안 보였음 | 유효한 SVG path와 정적 fallback, 실제 이동 frame 차이 확인 |
| 연출 | 방향 변경·위치 보정·체험 전환에 이전 timer가 상태를 덮을 수 있었음 | 서버 상태와 표시 상태 분리, cue/mode generation, 위치 보정 후 늦은 callback 검사 |
| 화면 | 모바일 판 우측이 잘리고 OBS에 scrollbar가 생김 | 판 전용 가로 scroll, 데이터 기반 비율; 390px 전체 페이지와 1280×720 OBS 검사 |
| 운영 명령 확장 | 모든 명령이 presentationEpoch를 바꿔 방향/재고 조작도 이동을 취소할 수 있었음 | 위치 보정·종료에서만 barrier 변경, 실제 PG 회귀 통과 |
| 운영 상태 | 세션과 재고/미션을 별도 시점으로 조회해 revision과 값이 어긋날 수 있음 | repeatable-read snapshot, 채널 권한과 역할을 함께 반영; 실제 PG 회귀 통과 |
| 세션 생성 | 서로 다른 명령의 동시 생성이 500, 재전송 결과가 이후 세션 변경에 따라 달라질 수 있음 | 채널 경합 409와 생성 시 응답 snapshot 보존 회귀 통과. 001의 불완전한 생성 ack는 GET/POST 모두 명시적 409 |
| 응답 유실 | 웹 재시도마다 새 commandId를 만들면 실제 동작을 반복할 수 있음 | 의도별 ID/본문 보존, 조회·동일 키 재시도; 커밋 후 응답 유실·새로고침과 미커밋 재시도 브라우저 확인 |
| 운영 종료 | 미완료 미션을 둔 채 종료하면 화면에서 후속 처리가 고립됨 | 미완료 작업이 있으면 종료 거부, 완료/면제/실드로 해결한 뒤 종료; PG·브라우저 확인 |
| 동기화 | 늦은 polling 응답이 최신 상태를 덮고 다른 운영자 이동이 표시되지 않을 수 있음 | 요청 순서·세션·revision·barrier 검사, idle 외부 이동 반영; 늦은 polling/주사위 응답 브라우저 확인 |
| 권한 회수 | mutation transaction 이전의 권한 확인과 실제 변경 사이에 회수 경합 | transaction 안에서 현재 권한/역할 재확인·잠금, PG 권한 회수 회귀 통과 |

| 웹 버튼 | pending 상태에서 일부 재고/미션 버튼이 여전히 활성 표시됨 | 서버 전송 가드에 더해 모든 신규 명령 버튼 잠금, 새 이미지에서 실제 재시도 흐름 재검증 |
| 웹 대비 | 위치 보정 버튼에 광범위한 CSS 선택자가 흰 글씨를 적용함 | 위험 동작 버튼 색상 우선순위를 명시하고 최종 화면 확인 |

위 항목은 로컬 preview 범위의 검증이다. 실제 수집·전체 효과·실시간 OBS·운영 배포의 리뷰를 대체하지 않는다.
