# 신청곡 리모컨 원본 이식

사용자는 일반 관리 페이지를 참고해 새로 만든 UI를 폐기하고, 신청곡 콘솔(리모컨)의 실제 코드를 완전히 가져온 뒤 수정하도록 명시했다. 기존의 잘못된 UI·관리자 구현 두 커밋은 revert했고, 이 작업은 그 코드에 스타일을 덧씌우는 변경이 아니다.

## 고정 원본과 범위

- 저장소: `dylabs/meloming-front`
- 고정 커밋: `3346d2e14c7823ae9d748cdd9f704e886e06ee19` (`515226a0^`, 외부 서비스 리다이렉트 전)
- 진입점: `src/app/(popup)/console/[user]/page.tsx`
- 실제 리모컨: `src/domains/overlay/components/live-console-content.tsx` (원본 5,898줄)
- 재귀 import·re-export·literal dynamic import로 확인한 실행 의존 165개 파일, popup layout/provider/CSS 5개, CSS의 추가 import 3개, PDF.js 자산 복사 스크립트 1개, 총 174개

원본 전부는 제품 저장소 밖에 추출하고 Git object의 바이트·SHA-256과 대조했다. 제품에는 파일별 허용 목록의 경로만 반입한다. 원본의 다른 페이지·배포 설정·Git 이력은 포함하지 않는다. 이는 원본 UI를 새로 재작성하는 방식이 아니며, 상단 탭·ResizablePanel·대기열·설정·팝업의 실제 컴포넌트가 출발점이다.

## 수정 경계

원본 UI 파일과 관련 훅/API의 코드 전체를 먼저 반입했다. 기존 운영 서비스에 연결하는 네트워크·인증·Socket.IO·분석 설정은 제품 경계로 분리한다. 서버가 없는 기능은 성공으로 위장하지 않고 미연결 상태 또는 명시적인 오류로 표시한다. 기존 서비스의 자격 증명, 운영 주소, 사용자 데이터는 반입 대상이 아니다.

원본 CSS의 색상 토큰·레이아웃·컴포넌트 클래스를 유지하며 폰트 로딩은 공식 NanumSquareNeo 자체 호스팅으로 바꾼다. 폰트의 SIL OFL 고지는 `apps/web/public/fonts/OFL.txt`에 포함한다. 의존 패키지는 원본 콘솔에서 실제 참조하는 항목과 Tailwind 빌드 도구만 추가한다. 자체 코드의 반입은 사용자의 명시 요청에 근거하며, 제3자 패키지는 각 패키지의 라이선스를 유지한다.

## 검증 기록

원본 저장소의 빌드나 개발 서버는 실행하지 않았다. 원본 추출 검증과 제품의 실행 검증은 구분한다. 배포 전 제품 타입 검사·빌드·원본 대비 변경 목록·비밀 값 검사 및 브라우저 네트워크 검증 결과를 이 기록에 추가한다.

제품 파일 174개와 허용 목록을 대조하여 누락 0개를 확인했다. 원본 그대로인 파일은 158개이고, 16개는 위 연결/폰트 경계에 해당한다. Sub Agent 검토에서 JSX·표시 문구·레이아웃 보존과 private 운영 호스트 제거를 확인했다. 원본 스냅샷·제품 소스·전체 staged 파일의 Gitleaks redacted 검사에서 탐지 0건이었다. 타입 검사와 웹 테스트 10개가 통과했다. 이 검증은 주루마블 게임 기능 연결 완료를 의미하지 않는다.
