# OBS 오버레이

운영 콘솔에서 채널의 읽기 전용 오버레이 주소를 조회하고 OBS Browser Source에 추가합니다. 통합 화면과 파츠별 화면은 같은 채널 상태를 표시합니다. 주소를 회전한 뒤에는 OBS의 기존 주소를 새 주소로 교체해야 합니다. 주소에 포함된 토큰은 방송 비밀값으로 취급합니다.

통합 화면은 게임판, 말, 주사위, 미션, 재고와 방송 패널을 배치합니다. 운영자는 화면 미리보기에서 위젯 위치, 크기와 표시 여부를 조정합니다. 저장된 배치의 revision으로 동시 변경을 확인하고, 재연결 시 서버 snapshot으로 동기화합니다. 확정된 게임 결과의 표시가 늦거나 재생이 중단되어도 게임 상태는 바뀌지 않습니다.

보드 테마는 라임 클로버, 핑크 버니, 스카이 소다, 라벤더 드림, 미드나잇 팝, 피치 소르베를 제공합니다. 콘솔 미리보기와 방송 보드는 같은 렌더러를 사용합니다. 글꼴 출처와 라이선스는 [폰트 안내](../apps/web/public/fonts/README.md)에 있습니다.

오버레이 URL은 읽기 전용 API와 Socket.IO 연결에 사용합니다. 방송 화면을 새로고침하면 서버 상태를 다시 읽으므로, 재연결을 게임 명령의 재실행으로 처리하지 않습니다.

## OBS 구성

1. 운영 콘솔의 오버레이 영역에서 통합 또는 파츠별 주소를 복사합니다.
2. OBS에 Browser Source를 추가하고 복사한 주소를 입력합니다.
3. 통합 화면은 1920×1080을 기준으로 배치하고, 파츠별 화면은 콘솔에 표시된 권장 크기를 사용합니다.
4. 콘솔 미리보기와 OBS 화면을 비교한 뒤 위젯의 위치·크기·표시 여부를 저장합니다.

게임판 테마와 패널 문구는 설정의 초안·검사·게시 흐름을 사용합니다. OBS에서 조정하는 실시간 배치는 별도의 live revision으로 저장합니다. 두 변경이 같은 화면에 적용되더라도 게시가 OBS 위젯의 위치를 임의로 초기화하지 않습니다.

말 이미지와 스타일은 채널별 설정입니다. 방송 화면의 말 이동은 서버가 보낸 경로를 따라 재생합니다. 늦게 도착한 snapshot이나 이전 세션의 연출은 새 게임 상태를 덮어쓰지 않습니다.
