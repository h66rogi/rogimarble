# 소스 이식과 공개 범위

## 이번 작업의 경계

대상 두 레포는 조사 당시 public이고 비어 있었다. 초기 참고 다섯 레포 중
`meloming-chat-collector`는 public, 나머지 네 개는 private이다.
추가 참고 `h66rogi/rogichat`은 public, `h66rogi/rogichat-ops`는 private이다.
대상은 독립 Git 저장소로 유지하며 원본의 커밋/태그/브랜치를 가져오지 않는다.

참조 clone과 상세 조사 기록은 대상 레포 밖의 `_references/rogimarble/`에 둔다.
현재 대상에 작성한 문서와 후원/보드 코어는 신규 작성물이다. 원본 구현 파일은
아직 이식하지 않았다.
`docs/assets/streamer-board-reference.png`는 사용자가 직접 제공한 참고 이미지의 변경 없는 사본이며,
보드 프리셋은 그 칸 정보를 데이터로 옮긴 것이다. private 참고 레포의 이미지/코드를 가져온 것이 아니다.

## 선별 이식 절차

1. 원본 HEAD를 고정하고 **파일별 허용 목록**을 만든다. 디렉터리 전체 wildcard를
   반입 허가로 취급하지 않는다. 필요한 내부 import와 테스트 의존성도 확인한다.
2. 원본 밖의 작업 공간에서 불필요한 도메인, 실데이터 fixture, 내부 주소,
   브랜드 자산, 운영 설정을 제거한다. 실제 코드의 작성 주체와 라이선스 고지도 확인한다.
3. 정리된 파일만 대상 경로에 넣고 코드·의존성·테스트 diff를 검토한다.
4. 이식 기록에는 원본 레포/커밋/경로, 대상 경로, 라이선스, 변경 이유,
   검증 결과를 남긴다. 내부 운영 정보가 든 상세 기록은 외부 참조 폴더에 보관한다.
5. **첫 커밋 전** staged 파일 전체를 확인하고 민감 값 검사를 한다.
   이후 첫 push 전에는 공개될 모든 커밋과 ref까지 확인한다.
6. 첫 커밋부터 공개 가능한 파일만 포함한다. 공개 PR의 CI는 최초 노출을 막는
   수단이 아니므로, 공개 후 검사하는 흐름에 의존하지 않는다.

원본 remote 추가/fetch, cherry-pick, merge, subtree, submodule, `.git` 복사,
mirror push를 이식 방식으로 사용하지 않는다. shallow clone이나 squash만으로
현재 스냅샷의 불필요한 코드 공개가 방지되지는 않는다. `.gitignore`도 이미
커밋한 파일이나 이력을 제거하지 않는다.

원본의 CI, Dockerfile, 도메인, 버킷명, 조직용 패키지 접근 설정은 그대로 옮기지
않고 필요한 환경에 맞게 다시 작성한다. 예시 환경 변수는 가상 값만 쓴다.
이미 노출된 이력을 정리해야 하는 상황이 생겨도 강제 push나 원격 삭제를
일방적으로 실행하지 않는다.

## 라이선스

공개 수집기의 현재 표기는 `AGPL-3.0-only`이며 `LICENSE`와 `NOTICE`가 있다.
그 코드를 가져올 때 고지를 삭제하거나 임의로 MIT 등으로 바꾸지 않는다.
별도 권리자 허락에 따른 이식이면 그 근거를 기록한다. private 레포가 접근 가능하다는
사실 자체를 제3자 코드·폰트·이미지까지 자유롭게 재배포할 수 있다는 뜻으로 해석하지 않는다.

AGPL 경로로 수정 버전을 제공할 경우 배포 및 네트워크 제공 조건도 반영해야 한다.
별도 레포/프로세스라는 이유만으로 결합 관계의 라이선스 판단을 단정하지 않는다.
현재 단계에서는 원본을 반입하거나 대상 전체의 라이선스를 확정하지 않았다.
`rogichat`의 자체 코드에는 `PolyForm-Noncommercial-1.0.0` 및 NOTICE가 있다.
IaC·배포 helper도 공개 여부만으로 자유로운 재라이선스를 가정하지 않고,
직접 이식할 파일의 고지·적용 조건 또는 별도 권리자 허락 근거를 기록한다.
private ops의 실제 manifest·주소·공개키·배포 증거는 public 대상에 복사하지 않는다.
참고: [GNU AGPL 본문](https://www.gnu.org/l/agpl),
[GNU FAQ](https://www.gnu.org/licenses/gpl-faq.html#AGPLv3CorrespondingSource).
