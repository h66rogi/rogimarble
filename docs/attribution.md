# 소스와 자산 출처

웹 콘솔과 통합 오버레이에는 다른 프로젝트에서 가져와 Rogimarble에 맞게 조정한 코드가 포함됩니다. 파일별 원본 경로, 고정 커밋, SHA-256과 변경 설명은 `docs/source-imports/song-request-console.json` 및 `docs/source-imports/total-overlay.json`에 기록되어 있습니다. 이 manifest는 디자인 보존 검사에도 사용됩니다.

추가 연동 코드와 배포 도구는 이 저장소의 경계에 맞춰 작성되었습니다. 기여 시 외부 코드를 가져온 경우 출처, 원본 라이선스, 수정 범위와 필요한 저작권 표시를 함께 검토해 기록하세요. 공개 접근 가능 여부만으로 재배포 권한이 부여되지는 않습니다.

방송용 말과 칸 일러스트는 `apps/web/public/artwork`에 있습니다.

폰트 파일과 각 라이선스는 [폰트 안내](../apps/web/public/fonts/README.md)를 참고하세요. 이미지와 방송 자산을 교체할 때에도 출처와 배포 권한을 확인하세요.
