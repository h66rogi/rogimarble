# 방송 게임판 테마

관리 화면의 **규칙·보드 → 방송 테마·배치**에서 같은 게임판을 여섯 가지 모습으로 비교한다.
라임 클로버(기본)·핑크 버니·스카이 소다·라벤더 드림·미드나잇 팝·피치 소르베를 제공한다. 선택은 초안에만 반영되며
저장·검증·게시 후 운영 보드와 OBS 통합 오버레이에 반영된다.

테마는 채널의 `overlay-layout` 문서에 `boardThemeId`로 저장한다. 기존 문서에
필드가 없거나 폐기된 `classic-party`가 저장되어 있으면 라임 클로버로 표시한다.
기존 초안은 편집기에 불러올 때 변환하고, 다음 저장 시 새 ID를 기록한다.
클래식 전용 렌더러와 선택 항목은 제거했다. 새 설정의 폐기된 ID, 알 수 없는 ID, null, 문자열 이외 값은
서버 검증에서 거부한다. 게임판의 stable cell ID·경로·도착 동작·설정 색상은
변경하지 않으며 세션 위치, 미션, 보상 수량, 게임 revision도 변경하지 않는다.
기존 위젯 위치·크기·배경 설정을 보존한다. 테마를 게시해도 숨겨진 게임판 위젯을
자동으로 켜지 않는다. 게임판 표시 여부와 패널 위치는 OBS 탭의 실시간 배치 편집기에서 설정한다.

방송 테마는 사용자가 제공한 참고 이미지의 넓은 중앙 공간,
테두리 글자, 모서리 장식이라는 시각적 방향을 반영한 신규 SVG/CSS다.
참고 이미지의 원본 그림이나 제3자 캐릭터를 자산으로 반입하지 않았다.
기존 제작 아트 및 나눔스퀘어네오를 재사용한다. 방송 글꼴은 추가로 주아·도현·검은고딕을 선택할 수 있다.
추가 글꼴은 공식 정적 파일과 OFL을 함께 자체 호스팅하며 콘솔 기본 글꼴은 바꾸지 않는다.

방송 판은 공통 `Board` 렌더러를 사용하므로 콘솔 미리보기와 OBS에서 같은 테마가
그려진다. 코너 장식은 격자 좌표로 정하며 칸의 이름/배열 순서로 판정하지 않는다.
자유 배치 보드에는 외곽 격자 전용 코너 장식을 만들지 않는다.

메뉴판과 주사위 가격 패널은 공통 `BroadcastPanel` 렌더러로 콘솔·OBS에 같은 모습을 표시한다.
게시된 후원 규칙의 자동 가격 또는 직접 입력한 표시 문구를 선택한다. 규칙 자동 표시에서
가격 후보가 없거나 주사위 1회 후보가 여럿이면 임의로 고르지 않는다. 후보를 지정하거나
표시 값을 직접 입력한다. 직접 표시한 금액은 후원 규칙을 수정하지 않는다.
