Only the variable WOFF2 is included. No conversion or subsetting was performed. The license applies to the font, not to this application.

The root layout registers this file once through `next/font/local` in `app/fonts.ts`.
Next.js generates the font-face, content-hashed asset URL and preload. The shared
`--font-sans` token connects console controls, headers, board and OBS HUD to that
registration; do not add a separate manual font-face or preload.
